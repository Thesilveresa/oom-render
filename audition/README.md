# Audition renders (new LED-wall piece)

46 unique configurations from `AllTheVersions` (54 saves; exact duplicates merged, latest save kept; see `candidates.json`).
Each is rendered straight from its `.lxp` (channels 1-2, no automation): 3 s settle, then 30 s at 1800 x 1800, 30 fps.

Artifacts on the run page:
- `Audition_Reel_900`: every candidate in order with a title card, 900 x 900, plus a chapter list (paste into a YouTube description for chapters).
- `Audition_Reel_1800`: the same reel at full size.
- `clip_<NN>_<name>`: each candidate's own 1800 clip, no title card.

`oom-render.jar` here is the OOM render jar plus LiquidLight, LiquidLight2 and Ferrofluids (Nov 20 optimized), sim fields on SIM_*.
